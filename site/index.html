Safe, previewable disk cleanup for Arch Linux.

Reclaim cache, log, build artifact, and package space through a read-only plan, a human confirmation gate, and one validated deletion funnel.

Install sweep View on GitHub

Safety by construction

Every destructive action passes compile-time protected roots, mount checks, and open-file detection before touching disk.

One deletion funnel

Every clean item goes through twenty validation checks and a single non-recursive unlinkat syscall.

Never runs as root

sweep refuses uid 0. System caches elevate only after confirmation via run0 or sudo with a fixed argv.

Recoverable where it matters

Interactive analyze deletions and uninstall leftovers move to freedesktop trash via renameat2.

Terminal previews

Inspect system health, preview a deterministic plan, or explore disk usage interactively.

sweep status: read-only snapshot of disk, package cache, orphan data, and user units.

Command suite

Focused subcommands for cache cleanup, project artifacts, AUR helpers, and pacman maintenance.

sweep clean Rule-based cache, log, and trash cleanup with dry-run preview and confirmation.
sweep purge Removes build artifacts only when paired with their project manifest.
sweep aur Cleans built .pkg.tar.* archives while keeping PKGBUILDs and sources intact.
sweep installer Removes stale downloaded .pkg.tar.zst, .iso, and .AppImage files.
sweep analyze Interactive TUI disk explorer and --largest report for scripts.
sweep uninstall Previews pacman -Rs transactions and moves exact-name leftovers to trash.
sweep status / doctor Read-only system health summary and mount/capability diagnostics.
sweep history / optimize Audits past operations from operations.jsonl and rebuilds user indexes.

Install

Install from the release tarball, build with Arch PKGBUILD, or compile from source with Cargo. 

gh release download -R ulaskizilay/sweep -p 'sweep-*-x86_64-linux.tar.gz' -p SHA256SUMS
sha256sum -c SHA256SUMS
tar -xzf sweep-*-x86_64-linux.tar.gz
install -m755 sweep-*/bin/sweep ~/.local/bin/
git clone https://github.com/ulaskizilay/sweep.git
cd sweep/packaging/sweep-cli
makepkg -si
